# Lab 02 – Breast Cancer Dataset Analysis

**File Name:** `23mid0344_lab_02.ipynb`

**Libraries Used:**

* NumPy
* Pandas
* Matplotlib
* Scikit-learn

**Abstract:**
This experiment performs data analysis and preprocessing on the Breast Cancer Wisconsin dataset. It includes dataset loading, data inspection, missing-value and duplicate checking, diagnosis encoding, feature and target separation, train-test splitting, correlation analysis, feature distribution visualization, and summary statistics.
